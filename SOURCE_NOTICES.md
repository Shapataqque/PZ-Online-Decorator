PZ Online Decoration Tool is source-derived from the supplied GPL/BSD-licensed PZ Mapping Tools source tree. The public application branding and internal TypeScript identifiers use the PZ Online Decoration Tool name.

Source-derived behavior includes Project Zomboid level-isometric map conventions, PZ texture-pack parsing, BuildingEd furniture definitions, WorldEd `.lotheader` / `.lotpack` formats, and the binary `.tiles` format used for per-tile object properties.

Relevant upstream license copies are retained under `licenses/`. No Project Zomboid tiles, textures, map binaries or other game assets are distributed with this application; users select their own local files at runtime.
