# Changelog

## 1.2.0 — 10 October 2026

- Moved media-folder selection to the main toolbar and improved local media indexing performance.
- Added searchable Furniture and Tiles libraries with metadata-aware search and clearer object names.
- Made Furniture the default asset tab and added numbered alternative appearances for furniture variants.
- Simplified editing into a unified scene without user-facing layer controls.
- Kept Imported Base editable and added Picker support for stacked and multi-tile furniture objects.
- Added selective Erase with a checkbox list for stacked objects.
- Added explicit H-code placement heights with Inspector and keyboard controls.
- Added placement previews for Pencil and Rectangle tools and **Esc** to clear the active selection.
- Added Z-level navigation with an adjacent-level reference grid.
- Refined View Filters for walls, roofs, indoor vegetation, railings, furniture, roads, and ground objects.
- Improved imported tree rendering.
- Improved media indexing by reusing texture-pack coverage and reading PNG dimensions without decoding complete images during indexing.
- Added stricter validation for local media files and project JSON files.
- Added a restrictive Content Security Policy, browser security headers, sandboxed feedback, and on-demand loading for the external feedback form.

## 1.0.0 — 10 October 2026

- First public release.
- Project Zomboid location import.
- Furniture and tile catalog.
- Multi-Z-level editing.
- View filters and editable layers.
- Graphics quality settings and performance optimizations.
- Dark and light themes.
- Feedback integration.
