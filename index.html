Getting StartedChoose your platform, select the correct Project Zomboid media folder, then load and edit a location.

    
  

  

    
    
    
  

  

    

      
    
        
  1. Find your Project Zomboid installationIn Steam, open Library → Project Zomboid → Manage → Browse local files.
    2. 
        
  2. Select the correct media folderThe usual path is C:\Program Files (x86)\Steam\steamapps\common\ProjectZomboid\media. In the browser folder picker, single-click the media folder, then click Upload. Double-clicking opens the folder instead of selecting it.
    3. 
        
  3. Wait for media indexingPZ Decorator scans the selected game files locally in your browser. Your game files are not uploaded.
    4. 
      

    

    

      
    
        
  1. Find your Project Zomboid installationIn Steam, open Library → Project Zomboid → Manage → Browse local files.
    2. 
        
  2. Select the correct media folderDo not select Project Zomboid.app. In Finder, right-click it and choose Show Package Contents, then open Contents → Java → media. The folder to select is Project Zomboid.app/Contents/Java/media.
    3. 
        
  3. If the browser cannot enter the app bundleIn the folder picker, press ⌘⇧G and go directly to …/Project Zomboid.app/Contents/Java/media, then select the media folder.
    4. 
        
  4. Wait for media indexingPZ Decorator scans the selected game files locally in your browser. Your game files are not uploaded.
    5. 
      

    

    

      
    
        
  1. Load a world locationAfter indexing finishes, click Load World Location, enter World X / Y or use Choose from Map, choose the load mode, and load the location.
    2. 
        
  2. Edit the baseChoose objects from Furniture or Tiles. Use Pencil to place, Erase to remove, Picker to select existing objects, and R to rotate furniture.
    3. 
        
  3. Save / reopen as JSONUse Save as .json to keep your project and Open .json file to continue later. The Project Zomboid media folder still needs to be selected when game assets are required.
