Changelog PZ Online Decoration Tool changes

1.1.12

10 October 2026
  • Legacy vegetation_trees_01 placeholders now always pass through the erosion-tree resolver instead of accidentally rendering raw placeholder textures.
  • Tree previews in Picker, Selection, Tiles, placement ghosts, Imported Base, and user-placed layers now use the same coordinate-aware resolved asset.
  • Escape clears the current tile/furniture selection and removes its Pencil placement preview.
  • Erase now opens a checkbox chooser for all visible objects on the clicked cell, allowing multiple specific objects to be removed in one operation.
  • Z-level editing now shows an elevated active grid, a dashed adjacent-level reference grid, and vertical hover connectors to make multi-level object alignment clearer.

1.1.11

10 October 2026
  • Replaced the incorrect legacy-tree alias fallback introduced in 1.1.10.
  • vegetation_trees_01 placeholders are now resolved per world coordinate against erosion tree families instead of mapping one tile name globally to an arbitrary jumbo sprite.
  • Tree previews use normal non-snow seasonal frames and a weighted size distribution, so imported forests no longer become rows of identical snowy XXL trees.
  • The resolver remains deterministic for the same world coordinates, keeping imported areas visually stable between reloads.

1.1.10

10 October 2026
  • Restored previews for legacy vegetation_trees_01 placeholders by resolving missing tree tiles against the Build 42 jumbo-tree texture packs.
  • Tiles whose names contain roof/roofs are now always classified as Roof before overlay metadata is considered.
  • Catalog furniture matching now treats padded and unpadded sprite indices as equivalent, fixing imported-base classification for Vegetation - Indoor and similar objects.
  • Furniture is now the default left-side tab and appears before Tiles.
  • Furniture and Tiles search now includes .tiles metadata such as CustomName, GroupName, material and other property values; common search synonyms are also supported.
  • Furniture cards prefer metadata-derived object names while keeping the original catalog category and index visible underneath.

1.1.9

10 October 2026
  • Removed Map/Center and all user-facing layer controls from the Inspector; internal stacking now works as one unified editable scene.
  • Pencil no longer creates duplicate backing layers when a drag revisits the same cell, and Erase works across all internal layers plus Imported Base.
  • Furniture variants are now labeled as Alternative appearance 1, 2, 3… instead of exposing W/N/E/S direction codes; R still cycles appearances.
  • Fixtures - Railings objects are classified under Fences & Railings, and animated_clock_01_1 is classified as Furniture for imported-base filtering.
  • Renamed Settings help labels to Credits/Display and improved selected-button contrast in light mode.

1.1.8

10 October 2026
  • Imported Base is editable again: unlock it to erase imported game objects while keeping undo/redo support.
  • Picker now treats catalog-matched sprites as full furniture objects, including single-tile furniture, so R rotation works after picking.
  • Pencil now places the currently selected furniture object as well as selected single tiles.
  • Placement-height presets are shown only as H-codes, with + / − keyboard shortcuts and Inspector controls for one-step adjustment.
  • Simplified furniture information in the Inspector by removing repeated Furniture labels and layer text.

1.1.7

10 October 2026
  • Replaced Ground / Surface / OnTable logic with explicit numeric placement heights.
  • Common height presets are derived from Surface and ItemHeight values found in the loaded media folder.
  • Added Floor, named height presets, and a Custom height input in the Inspector.
  • Imported Base is now permanently read-only; all new decorations are written to user layers.
  • Preview and committed placement now use the same vertical-position function, eliminating preview/final height mismatches.
  • JSON projects now store per-cell numeric placement heights.

1.1.6

10 October 2026
  • Moved media-folder selection to the main toolbar and added a first-run media prompt.
  • Media assets now index automatically after the folder is selected, without loading a world location.
  • Renamed Load PZ Location to Load World Location and made Area around coordinate the default load mode.
  • Removed tile-property text from the Inspector selection summary.
  • Improved Ground / Surface / OnTable placement for tabletop-authored sprites whose vertical offset is baked into the packed sprite frame rather than exposed as IsSurfaceOffset.

1.1.5

10 October 2026
  • Fixed placement of sprites that use IsSurfaceOffset so Ground can place them back on the floor instead of keeping their authored tabletop height.
  • Surface and OnTable now use a target-height minus source-surface-offset calculation instead of stacking an extra vertical lift.
  • Imported base objects keep their original game alignment while newly placed objects use the selected placement mode.
  • Placement previews now use the same corrected height calculation as committed objects.

1.1.4

10 October 2026
  • Removed the coordinate map chooser and the PZmap.org helper entirely; World X / Y are now entered directly.
  • Restored Ground, Surface, and OnTable placement controls.
  • Ground places the object on the floor; Surface uses the ItemHeight of the existing destination object; OnTable uses the destination table/counter surface height.
  • Picker and Furniture selections now start in Ground mode so a previously elevated object does not carry its old height into a new placement.

1.1.3

10 October 2026
  • Removed the built-in tutorial entirely.
  • Replaced the slow local coordinate-map renderer with a fast PZmap.org reference workflow and coordinate paste helper.
  • Removed the Ground / Surface / OnTable controls and switched tabletop placement to automatic destination-based snapping.
  • Picking an object from a table no longer preserves the table-top height as the object's future placement reference.

1.1.2

10 October 2026
  • Replaced the coarse coordinate overview with a locally rendered top-view map based on map-square tile stacks.
  • Appliances and furniture-named tiles now take priority over conflicting Doors & Windows metadata in View Filters.
  • Aligned the Z-level dropdown and up/down controls.
  • Improved Picker recognition of imported multi-tile furniture by matching canonical tileset name and tile index.
  • Added explicit Ground, Surface, and OnTable placement modes below the rotation controls.
  • Hardened tutorial step 2 so Load PZ Location opens reliably before advancing.

1.1.1

10 October 2026
  • Reworked the coordinate map into a colored terrain overview with roads, vegetation, water, urban areas, and building footprints.
  • Added a heuristic tabletop-placement fallback for TVs, radios, computers, lamps, and similar small objects.
  • Added Z-level up/down buttons next to the existing Z dropdown.
  • Refined View Filters with separate Roads & Ground, Vegetation, and Fences & Railings categories.
  • Rectangle now shows the same semi-transparent placement preview while dragging.
  • Fixed repeated erasing of the same cell during a single drag stroke and added an exportable edit log for debugging.
  • Picker can now select a complete multi-tile furniture object from one of its component tiles.
  • Adjusted tutorial interaction and simplified tutorial wording.

1.1.0

10 October 2026
  • Improved the interactive tutorial flow around Load PZ Location.
  • View Filters now affect only the currently selected Z level.
  • Improved tile classification for several indoor vegetation, school, and counter sprites.
  • Picker now lets you choose between multiple objects on the same cell.
  • Added semi-transparent placement previews before placing tiles and furniture.
  • Added surface-aware placement for tabletop objects such as TVs and radios.
  • Added an optional zoomable map overview for choosing World X / Y coordinates.

1.0.0

10 October 2026
  • First public release.
  • Project Zomboid location import.
  • Furniture and tile catalog.
  • Multi-Z-level editing.
  • View filters and editable layers.
  • Graphics quality settings and performance optimizations.
  • Dark and light themes.
  • Feedback integration.
