Changelog PZ Online Decoration Tool changes

1.2.0

10 October 2026
  • Faster local media indexing and metadata-aware Furniture / Tiles search.
  • Furniture is the default asset tab with numbered alternative appearances.
  • Unified scene editing with editable imported objects and no user-facing layer controls.
  • Picker supports stacked and multi-tile objects; Erase can remove selected stacked objects.
  • Explicit H-code placement heights, keyboard height controls, placement previews, and Esc to clear selection.
  • Improved Z-level navigation and adjacent-level grid references.
  • Refined View Filters and imported tree rendering.
  • Stricter validation for local media and JSON project files.
  • Updated browser security policy and sandboxed, on-demand feedback loading.

1.0.0

10 October 2026
  • First public release.
  • Project Zomboid location import.
  • Furniture and tile catalog.
  • Multi-Z-level editing.
  • View filters and editable layers.
  • Graphics quality settings and performance optimizations.
  • Dark and light themes.
  • Feedback integration.
